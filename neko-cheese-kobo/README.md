# ねこのチーズ工房 〜ミルクから生まれる魔法〜

7歳くらいの子どもが、チーズ職人の猫「ミルク」と一緒に、牛乳からチーズができるまでを体験するブラウザ向け 3D アドベンチャーです。iPhone の Safari を最優先に作っていて、PC のブラウザでも遊べます。

## 遊べる内容

| 章 | 内容 | 体験すること |
| --- | --- | --- |
| 第1章 うしさんの ぼくじょう | 3D の牧場を歩く | 地面タップで移動、牛（ホルスタイン・ジャージー・子牛）にタッチ、牛乳の中身を 100 粒で観察、ミルク缶を工房へ運ぶ |
| 第2章 ぎゅうにゅうの なかの ちいさな せかい | 虫眼鏡で小さくなる | 脂肪球・カゼインを観察、乳酸菌に乳糖を届けると乳酸ができ、分裂して増える |
| 第3章 ぎゅうにゅうが ぷるぷるに！ | 大きな鍋で凝固 | 牛乳を注ぐ、温度を 30〜34℃に合わせる、スターター・レンネットを入れる、カゼインがつながる様子を魔法の窓で見る、カードをぷるぷる揺らす |
| 第4章 チーズしょくにんに なろう | 職人の作業 | 指でなぞってカードを切る、かき混ぜる、ホエイを抜く、型に詰める、押す／押さない、塩をふる、マークを選ぶ（**切り方と押し方で、やわらかい／ほどよい／かたいチーズに変わる**） |
| 第5章 じかんの まほう | 熟成庫 | 大きな扉を開け、ダイヤルで時間を進めると色・皮・大きさ・中身が変化（白カビタイプは白カビが育つ）。熟成しないフレッシュチーズも紹介 |
| 最終章 ねこの チーズショップ | お店と図鑑 | 自分のチーズを飾り、5種類のチーズを回転・拡大・断面観察。種類ごとの製法の違いを解説 |

各章には「ひみつ」が2つずつ隠れています（どの章にもいる ねずみのチュウ、よつばのクローバー、窓からのぞく牛、3年ねかせたチーズ、やぎのチーズなど）。見つけるとタイトル画面の「ひみつ ずかん」に残り、くり返し遊ぶ楽しみになります。

章をクリアするたびに、ミルクの「きせかえ」（リボン、花かんむり、めがね、星の髪かざり、マント、チーズの王冠）がもらえます。タイトル画面の「きせかえ」でミルクに着せると、そのまま冒険に一緒に来てくれます。ミルクは指でなでると、ごろごろ喉を鳴らしてハートを出します。

正解・不正解の罰やゲームオーバーはありません。どの選択肢を選んでも、猫がやさしく受け止めて正しい知識につなげます。

## 科学的な内容について

物語はファンタジーですが、説明は次の点に気をつけています。会話はテンポよく進むよう短くしてあり、下の項目のうち細かい話（殺菌、レンネットの由来、パニール、ホエイの色やリコッタ、カロテンなど）は台詞からは省いています。チーズごとの違いは最終章の図鑑カードで読めます。

- 乳酸菌は乳糖を使って乳酸をつくり、牛乳を少し酸っぱくする（味・香り、凝固の助け、雑菌の抑制）。本物は目に見えない大きさで、顔は分かりやすくするための表現だと作中で伝える
- レンネットの酵素（キモシン）がカゼインのまわりの「くっつかないバリア」を切り、カゼイン同士がカルシウムの助けでつながって網目になり、脂肪や水を閉じ込めて固まる。冷やしても牛乳は固まらない。酸と熱だけで固めるチーズ（パニールなど）もある
- カード（固まり）とホエイ（液体）の違い、ホエイの黄緑色はビタミンB2、ホエイはリコッタなどに使われる
- 温度や時間は「ほんとうは 30分〜1時間くらい」など実際の目安を示し、ゲーム内では「はやおくり」していることをはっきり見せる
- チーズの種類ごとに製法が違う（モッツァレラ／カマンベール／チェダー／エメンタール／ゴルゴンゾーラを別々の工程で説明）。プレイヤーのチーズは「オリジナル」と明示
- すべてのチーズが熟成するわけではない（フレッシュチーズ）。チーズの色は草のカロテン、アナトーによる着色、真っ白なチーズもある
- 白カビ・青カビは選ばれた食べられるカビで、家の食べ物に生えたカビは食べないこと

## 技術構成

- Vite + React 19 + TypeScript
- Three.js / React Three Fiber / drei
- zustand（状態管理）
- 3D モデルはすべて Three.js の基本形状を組み合わせたプロシージャルモデル。テクスチャも Canvas でその場に描くため、画像・モデルファイルは不要です。後から glTF などの高品質アセットに差し替えられるよう、キャラクター（`src/three/characters/`）と小道具（`src/three/props/`）は独立したコンポーネントにしてあります
- 効果音と BGM は Web Audio API でその場で合成（音声ファイル不要）
- 猫の声はブラウザ標準の音声読み上げ（Web Speech API）。使えない環境でも字幕と口パクで進行します
- 外部 API・API キーは不要。オフラインでも基本機能が動きます（Google Fonts の丸ゴシックだけ読み込み、失敗しても端末のフォントで表示）

### スマホ向けの工夫

- 描画解像度は最大 2 倍、重いときは `PerformanceMonitor` で自動的に下げる
- 影は軽い「ぼかし影」、草・花・木・棚のチーズなどは InstancedMesh で描画回数を削減（各章 200 ドローコール未満）
- 章ごとにコード分割して必要なときだけ読み込み、章を離れるとジオメトリ・マテリアルを解放
- 縦画面では視野角とカメラ距離を自動調整し、被写体を会話ウィンドウより上に配置
- `100dvh`・セーフエリア対応、ダブルタップ拡大や長押しメニューを抑制
- 進み具合（章・スタンプ・作ったチーズ・設定）は localStorage に保存。再読み込みしても続きから遊べます（章の途中からではなく、章の最初から再開）

## 開発

```bash
cd neko-cheese-kobo
npm install
npm run dev      # http://localhost:5173
npm run build    # 型チェック + 本番ビルド（dist/）
npm run preview  # ビルド結果の確認
```

URL に `?debug` を付けると、ブラウザのコンソールから `window.__neko` で章の移動や会話の操作、描画負荷の確認ができます。

### ディレクトリ

```
src/
  App.tsx               画面の切り替え（タイトル／プレイ／クリア／エンディング）
  game/                 会話エンジン、進捗保存、章の情報、チーズの判定
  audio/                効果音・BGM・読み上げ
  three/                3D の共通部品（舞台、カメラ、キャラクター、小道具、背景）
  chapters/chN-*/       章ごとのシーン（Scene.tsx）と台本（script.ts）
  ui/                   会話ウィンドウ、HUD、各種画面、ダイヤルなど
```

台本は `chapters/*/script.ts` に、台詞・選択肢・タスク（プレイヤーの操作待ち）を並べる形で書いてあります。`[乳酸菌:にゅうさんきん]` のように書くと、画面ではふりがな付き、読み上げでは漢字で読みます。

## Vercel へのデプロイ

リポジトリのルート（保守度診断アプリ）の `npm run build` が、`scripts/build-cheese.js` でこのゲームもビルドし、`public/cheese` に置きます。そのため、すでに GitHub と連携している Vercel プロジェクトに push するだけで、同じサイトの **`/cheese`** で遊べます（Vercel 側の設定変更は不要）。

ゲームだけを独立したサイトにしたい場合は、Vercel で Root Directory を `neko-cheese-kobo` にした別プロジェクトを作れば、同梱の `vercel.json` でそのまま動きます。
